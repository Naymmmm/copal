# Quick Start

This guide will walk you through your first Copal session.

## Running Copal Interactively

The easiest way to use Copal is in interactive mode:

```bash
lune run src/main.luau
```

You'll see a menu with three operating modes:

1. **Swarm Mode** - Best for specific, well-defined tasks
2. **Director Mode** - Best for complex goals requiring planning and review
3. **Company Mode** - Experimental high-level orchestration

## Your First Swarm Task

Select **Swarm Mode** and enter a task like:

```
Analyze the src folder and write a summary report
```

The swarm will:
- Spawn multiple worker agents
- Distribute the task among them
- Coordinate their work via the blackboard
- Return consolidated results

<Callout type="tip">
Swarm mode works best for tasks that can be broken down into independent subtasks. For complex projects requiring coordination and review, use Director Mode instead.
</Callout>

## Your First Director Task

Select **Director Mode** and enter a goal like:

```
Refactor the authentication module to use JWT tokens
```

The Director will:
1. Break down the goal into a plan of subtasks
2. Execute each subtask via the swarm
3. Review the results
4. Iterate if necessary (up to 3 review cycles)

## Using CLI Arguments

You can bypass the interactive menu for automation:

```bash
# Run a specific task with a swarm
lune run src/main.luau -- --mode swarm --task "Analyze the src folder and write a report"

# Run with Director
lune run src/main.luau -- --mode director --goal "Refactor the authentication module"
```
